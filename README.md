# Estudo dirigido — DETRAN-SP

Plano de estudo para o concurso de **Agente Estadual de Trânsito do DETRAN-SP**
(banca Instituto Avalia, prova em 1º de novembro de 2026).

Um cartão por dia até a prova. Cada dia traz a hora dividida, o texto da lei,
questões no estilo da banca e um botão para ouvir cada artigo em voz alta.

O texto dos artigos vem da **Lei 9.503/97 (Código de Trânsito Brasileiro)**,
extraído do site do Planalto, já com as alterações das Leis 14.071/2020 e
14.440/2022.

Abre em qualquer navegador, funciona no celular e não precisa de login.

## Na tela de início

Abrindo pelo endereço publicado, o menu do navegador tem "Instalar app" ou
"Adicionar à tela de início". Ele passa a abrir sem barra de endereço, com
ícone próprio, e continua abrindo sem internet depois da primeira visita.

Precisa de https para isso — o GitHub Pages serve assim. Abrindo o arquivo
direto do disco a página funciona igual, só não instala.

O ícone é gerado a partir de `icone.svg`, que é a fonte da verdade:

    node scripts/icone.js
